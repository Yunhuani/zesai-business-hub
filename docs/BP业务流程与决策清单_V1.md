## 一、完整用户旅程（已确认）

```
1.  入口      客户在网站找到「商业计划书」
2.  采集      对话式回答八模块问题（可保存草稿、断点续填）
3.  提交      点「生成」→ 预检积分 ≥1500 → 不足则引导购买
4.  扣费      够则扣 1500，创建记录（事务内幂等扣费）
5.  生成中    等待约 26 秒，显示处理中页面
6.  完成      跳转报告页
7.  查看      在线阅读完整 BP
8.  下载      PDF 免费下载，可重复下载
9.  进阶      报告页「联系顾问」入口 → 人工深度服务
10. 历史      「我的商业计划书」列表，随时回看与重新下载
11. 失败      自动退款 + 可重试
```

**总体与 NBG 诊断流程一致，可复用其成熟模式。**

## 二、计费决策（已确认）

| 项目 | 决策 | 说明 |
|---|---|---|
| BP 生成 | **1500 积分** | 配置键 `action.business_plan`，数据库已改、代码从配置读取 |
| 扣费时机 | **提交生成时** | 与 NBG 一致，事务内扣费 |
| PDF 下载 | **免费** | 含在 1500 内，与 NBG 的 `action.diagnosis_pdf = 0` 一致 |
| 重复下载 | **免费** | 与 NBG 的 `action.report_redownload = 0` 一致 |
| 生成失败 | **自动退款** | 幂等退款，billing key `business_plan_full` / 退款键 `refund:business_plan_full` |
| 重试 | **按 NBG 现有原则** | 失败已退款，重试重新扣费；最多 3 次 |
| 人工服务 | **不另设价格** | ¥9999 是通用人工服务定价、非 NBG 专属；BP 顾问入口走同一套流程，实际价格由后台人工沟通确定 |

**成本参考（引擎侧三次实测）**：单份 BP LLM 调用 38–43 次、耗时 24–28 秒、搜索 0–1 次。定价按调用上限估算。

## 三、功能边界（已确认）

### 第一版做

- 八模块正文生成与渲染
- PDF 下载
- 联系顾问入口（带 businessPlanId，供人工顾问查看该客户的 BP）
- 历史列表
- 失败退款与重试

### 第一版不做

| 不做的 | 原因 | 后续 |
|---|---|---|
| **Executive Summary（执行摘要）** | BP 仅 16–20 页，摘要的"代替阅读"功能不必要；且输入为二手内容、易失真 | 上线后按客户与投资人反馈评估 |
| **模块0 项目概况独立成页** | 主营业务、团队规模、成立时间在模块2/8 中已有更完整呈现，单独一页属重复 | 公司名与 slogan 放封面 |
| **重新生成 / 单页重生成** | 实现复杂度高 | **客户不满意只能重走完整流程（重新扣费）或自行修改 PDF。上线后若客户抱怨集中，这是第一个要补的功能** |
| **配色主题切换** | 需配套产品交互设计（在哪选、何时选、存哪里） | CSS 变量结构预留，加主题只需加变量组 |
| **AI 生图配图** | 成本、稳定性、合规均需单独评估 | 二期 |

## 四、视觉决策（已确认）

- **第一版单套主题：墨绿金**
  ```
  --pri: #1F3D32   深森林绿（主色）
  --acc: #C9A24B   暖金（强调）
  --bg:  #FAFAF8   暖白底
  ```
- 选择理由：与 NBG 诊断报告的视觉语言一脉相承，客户拿到两份产出能看出是同一平台，品牌一致。
- **视觉参照物：`智造云BP_自研V2.html`**（经多轮确认的设计定稿样例）。实现时以它为准，不要仅凭文字描述还原。
- 结论收口条：每模块底部深色条，**直接放结论文字，无任何标签前缀**。
- 图表一律内联 SVG，不引入图表库。

## 五、渲染时的特殊处理（易漏，务必检查）

1. **待补充项的过滤**：`pending_items` 中以下字段是引擎搜索产物、**不是客户应补充的内容，必须过滤不展示**：
   - `competitors[*].public_evidence`
   - `market_validation`
   
   其余（website、mission、vision、why_now、net_margin）为客户确实未提供，正常标注。

2. **品牌字段不做文本处理**：slogan、one_liner 属客户品牌表达，原样呈现，**不做标点规范化**。

3. **正文文本规范化**：客户原文可能用半角标点、句尾无句号。正文描述性内容统一转全角、补句号，使改写内容与原文内容风格一致。

4. **封面空字段不占位**：mission、vision 为空则不显示该行，不显示"待补充"。

5. **防溢出**：内容区块设最大高度与溢出处理，禁止元素重叠或文字截断。
